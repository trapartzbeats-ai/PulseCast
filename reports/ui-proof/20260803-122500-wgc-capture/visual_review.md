# Visual Review

The packaged Settings screen keeps capture selection, state, telemetry, and
lifecycle control in one PlayStation Source card. The active state shows
`CAPTURE REAL`, a rising frame count, resolution, executable identity, and a
Stop action. The stopped state changes to `CAPTURE STOPPED` and relabels the
retained values as last-capture data.

The source boundary remains visible: process audio and Program composition are
unavailable. No official Sony client or PS5 claim is shown.

Status: PASS for the fault-injected capture-control slice.
